# Eva的資料庫

收藏日文文法漫畫、互動學習單元與錯題筆記的學習資料庫。首頁提供四個資源入口，採暖白與鼠尾草綠配色。原有錯題資料、同步碼儲存鍵與後端 API 均維持相容。

手機延續既有拍照建檔模式，並可閱讀日文漫畫；互動教材與完整錯題整理功能使用桌機。

## 已完成功能

- 新增、編輯、刪除錯題
- 科目與複習狀態篩選
- 關鍵字搜尋
- 隨機抽題重做
- 錯題統計
- 瀏覽器 LocalStorage 自動儲存
- 內建生物錯題範例
- GitHub Pages 自動部署流程
- Gemini 互動 HTML 多檔批次匯入
- 互動學習單元與結構化題目同步保存至 D1
- 從錯題資料庫重新開啟原始互動頁

## v4.0 資料庫升級

部署新版 Worker 前，先在 `worker` 目錄執行一次：

`npx wrangler d1 execute ai-mistake-learning-db --remote --file=schema.sql`

再執行 `npm run deploy`。`schema.sql` 使用 `CREATE TABLE IF NOT EXISTS`，不會刪除既有錯題。

## 錯題格式

每一題包含：

1. 題目
2. 正確答案
3. 我的答案
4. 我的錯誤
5. 解題觀念
6. 知識點
7. 詳細解答
8. 錯誤類型標籤
9. 複習狀態

## 開啟 GitHub Pages

1. 進入 Repository 的 `Settings`
2. 點選左側 `Pages`
3. 在 `Build and deployment` 的 `Source` 選擇 `GitHub Actions`
4. 等待 Actions 部署完成
5. 網站網址預計為：

`https://yuningliu52018-ship-it.github.io/ai-mistake-learning/`

## 注意

目前錯題資料儲存在瀏覽器的 LocalStorage，因此不同裝置不會自動同步。後續版本會加入匯出／匯入與雲端同步功能。

## 59 張有聲漫畫

`voiced-comic.html?comic=<漫畫 ID>` 由同一份播放器與 `voiced-comics-data.js` 提供全部 59 張漫畫的逐格閱讀和 Google 日語 AI 合成朗讀。沒有 query 的舊網址仍開啟第1課第一張。原有 29 張圖片、圖庫文案與原句／補充標示不變；新增獨立的初級複習 J1 分類13張、J2分類17張。

- 236 格依原圖實際上下或 2×2 順序切換，共 204 句日文。純情境、公式／重點圖解不虛構配音，可手動選格閱讀。
- 每張卡片、放大閱讀工具列都有有聲入口；播放器可選擇漫畫、上一張／下一張，或返回該課與完整原圖。
- 沿用原日文網站的 Google Translate 日語線上音源，以 HTML Audio 播放，保留 no-referrer 頁面政策。只在按播放後連線；不產生匯出音檔或錄音。
- 一般 0.95／慢速 0.82；連續聽、逐句跟讀停頓、暫停、停止、重頭播放與本句重播。
- 字幕保留原圖漢字。中文姓氏林／王分別讀りん／おう；鬍鬚張讀ひげちょう，滷肉飯讀ルーローハン；Ado／阿斗按對話的誤聽情境同讀あど。食物的辛讀から，7時讀しちじ。
- 同一個 Audio 元素用於後續句子。暫停後繼續從本句重播；只有實際音訊開始與結束才推進，視覺提示格不送出空的 Google 請求。
- 載入失敗、播放被擋或逾時停在本句並提供重試；完全沒有裝置語音替代。
- 切換格數／漫畫／離頁會取消音訊；進背景會暫停。取消清除事件與計時器，避免過期事件改變句子。
- 需要網路，音源可用性受 Google 服務影響。iPhone 若遇到播放限制，可直接在 Safari 按「重試播放」。

完整靜態與播放器狀態測試：`node --test tests/*.test.cjs`。

## 日英雙語切換

目前已有 5／59 張在同一張卡內提供英文情境改編。圖庫仍以每個日文主題計一張，共59張；原有日文資料與圖片，以及第一張英文版均保持不變。每張英文版按原圖場景自然改寫英文學習重點，不把日文文法當作一一對應的英文規則。

- 閱讀器與有聲頁可選「日文版／英文版」，同步切換漫畫、台詞、中文解說及 Google 語言。
- 圖片與每段英文都標為「英文情境改編」，不宣稱是原教材的英文原句。
- 英文有聲網址在原漫畫網址加上 &lang=en；複製網址與瀏覽器返回／前進保留版本。
- 上一張／下一張與漫畫選單在目的漫畫已有英文版時延續英文；尚未提供時開啟日文。
- 切換版本停止音訊、清除跟讀倒數並重設第一格；不自動播放。慢速與跟讀設定保留。
- 英文圖為1024×1536完整無損WebP，與驗證PNG像素一致；逐格裁切和台詞次序按實際圖核對。純解說格可閱讀且不送出語音請求。
- Google音源維持 no-referrer；錯誤會停止並提供重試，不使用裝置語音替代。
