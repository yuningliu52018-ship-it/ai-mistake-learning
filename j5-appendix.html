變化表的日文朗讀依序讀出原形與變化；英文只對照變化後的意思，不硬套日語活用。例句的「我／它」等主詞是英文所需的情境補充。原句、縮寫與新增示範各自標示。

用途與評價的「の＋に」含名詞化的の，與轉折的のに不同。示範情境不代表實際健康、商品或旅遊建議。

たら各詞性4 組

筆記規則整理；示範詞部分為補充

  • 動詞：行く→行ったら／行かない→行かなかったら
  • い形容詞：おいしい→おいしかったら／おいしくない→おいしくなかったら
  • な形容詞：暇→暇だったら／暇じゃなかったら
  • 名詞：雨→雨だったら／雨じゃなかったら

  1. 依筆記規則補充示範；英語語意對照

    行く → 行ったら 行かない → 行かなかったら

    如果去；如果不去。

    If I go. If I don't go.

    如果去；如果不去。

  2. 依筆記規則補充示範；英語語意對照

    おいしい → おいしかったら おいしくない → おいしくなかったら

    如果好吃；如果不好吃。

    If it tastes good. If it doesn't taste good.

    如果好吃；如果不好吃。

  3. 依筆記規則補充示範；英語語意對照

    暇 → 暇だったら 暇じゃない → 暇じゃなかったら

    如果有空；如果沒空。

    If I'm free. If I'm not free.

    如果有空；如果沒空。

  4. 依筆記規則補充示範；英語語意對照

    雨 → 雨だったら 雨じゃない → 雨じゃなかったら

    如果下雨；如果沒下雨。

    If it's rainy. If it isn't rainy.

    如果下雨；如果沒下雨。

ても各詞性4 組

筆記規則整理；示範詞部分為補充

  • 動詞：降る→降っても／飲まない→飲まなくても
  • い形容詞：おいしい→おいしくても／おいしくなくても
  • な形容詞：暇→暇でも／暇じゃなくても
  • 名詞：雨→雨でも／雨じゃなくても

  1. 依筆記規則補充示範；英語語意對照

    降る → 降っても 飲まない → 飲まなくても

    即使下雨；即使我不喝。

    Even if it rains. Even if I don't drink it.

    即使下雨；即使我不喝。

  2. 依筆記規則補充示範；英語語意對照

    おいしい → おいしくても おいしくない → おいしくなくても

    即使好吃；即使不好吃。

    Even if it tastes good. Even if it doesn't taste good.

    即使好吃；即使不好吃。

  3. 依筆記規則補充示範；英語語意對照

    暇 → 暇でも 暇じゃない → 暇じゃなくても

    即使有空；即使沒空。

    Even if I'm free. Even if I'm not free.

    即使有空；即使沒空。

  4. 依筆記規則補充示範；英語語意對照

    雨 → 雨でも 雨じゃない → 雨じゃなくても

    即使下雨；即使沒下雨。

    Even if it's rainy. Even if it isn't rainy.

    即使下雨；即使沒下雨。

ば／なら其他詞性5 組

筆記規則整理，最後一項為查核補充

  • い形容詞：おいしい→おいしければ／おいしくなければ
  • いい→よければ；ない→なければ
  • な形容詞：有名なら／有名じゃなければ
  • 名詞：日本なら／日本じゃなければ
  • 名詞、な形容詞另有ならば、であれば等形式；本課先學なら。

  1. 依筆記規則補充示範；英語語意對照

    おいしい → おいしければ おいしくない → おいしくなければ

    如果好吃；如果不好吃。

    If it tastes good. If it doesn't taste good.

    如果好吃；如果不好吃。

  2. 依筆記規則補充示範；英語語意對照

    いい → よければ ない → なければ

    如果可以；如果沒有。

    If that's okay. If there isn't any.

    如果可以；如果沒有。

  3. 依筆記規則補充示範；英語語意對照

    有名なら 有名じゃなければ

    如果很有名；如果不出名。

    If it's famous. If it isn't famous.

    如果很有名；如果不出名。

  4. 依筆記規則補充示範；英語語意對照

    日本なら 日本じゃなければ

    如果目的地是日本；如果目的地不是日本。

    If the destination is Japan. If the destination isn't Japan.

    如果目的地是日本；如果目的地不是日本。

  5. 查核補充形式；示範詞與英語對照為補充

    学生ならば／学生であれば 静かならば／静かであれば

    如果是學生；如果安靜。每組兩種說法意思相近，であれば較正式。

    If you are a student. If it is quiet.

    如果是學生；如果安靜。每組兩種說法意思相近，であれば較正式。

四種條件句焦點4 組

筆記概念整理與查核修正

  • と：自然、常態、操作結果，或發現；本課著重前幾種。
  • たら：條件成立後的結果或下一步，能接請求。也有過去發現用法。
  • ば：著重後項成立需要什麼條件。
  • なら：承接話題／假定並提出建議，前後時序不一定相同。

  1. 原筆記例句；英語對照補充

    このつまみを右へ回すと、音が大きくなります。

    把這個旋鈕向右轉，聲音就會變大。

    If you turn this knob to the right, the sound gets louder.

    把這個旋鈕向右轉，聲音就會變大。

  2. 依筆記規則補充示範；英語語意對照

    仕事が終わったら、電話してください。

    工作結束後，請打電話給我。

    Please call me when you've finished work.

    工作結束後，請打電話給我。

  3. 原筆記例句；英語對照補充

    安ければ、買いますが、高ければ、買いません。

    便宜的話就買，貴的話就不買。

    If it’s cheap, I’ll buy it. If it’s expensive, I won’t.

    便宜的話就買，貴的話就不買。

  4. 原筆記例句；英語對照補充

    旅行なら台湾がいいですよ。

    旅行的話，台灣很不錯喔。

    If you’re looking for a trip idea, I recommend Taiwan.

    旅行的話，台灣很不錯喔。

に評價系列7 組

筆記規則整理

  • N＋に／V原形＋の＋に：いい・悪い・便利・不便・役に立つ・必要
  • V原形＋の＋に使う：用於做某事
  • 這個の是名詞化；不能與逆接のに混讀。

  1. 依筆記規則補充示範；英語語意對照

    この本は日本語の勉強にいいです。

    這本書適合用來學日文。

    This book is good for studying Japanese.

    這本書適合用來學日文。

  2. 依筆記規則補充示範；英語語意對照

    体に悪い。

    對身體不好。這裡只練習詞組，未指定任何物品或行為。

    Bad for your health.

    對身體不好。這裡只練習詞組，未指定任何物品或行為。

  3. 依筆記規則補充示範；英語語意對照

    このかばんは旅行するのに便利です。

    這個包包用來旅行很方便。

    This bag is handy for traveling.

    這個包包用來旅行很方便。

  4. 依筆記規則補充示範；英語語意對照

    この町は買い物をするのに不便です。

    這個城鎮買東西不方便。

    Shopping is inconvenient in this town.

    這個城鎮買東西不方便。

  5. 原筆記例句；英語對照補充

    この辞書は単語を調べるのに役に立ちます。

    這本字典對查單字很有幫助。

    This dictionary is useful for looking up words.

    這本字典對查單字很有幫助。

  6. 依筆記規則補充示範；英語語意對照

    この道具は箱を作るのに必要です。

    做箱子需要這個工具。

    You need this tool to make a box.

    做箱子需要這個工具。

  7. 原筆記例句；英語對照補充

    このはさみは髪を切るのに使います。

    這把剪刀是用來剪頭髮的。

    These scissors are used for cutting hair.

    這把剪刀是用來剪頭髮的。

ので／のに接續6 組

筆記規則整理

  • 動詞／い形容詞普通形＋ので／のに
  • 名詞／な形容詞現在肯定：なので／なのに
  • 用事があるので…：因為有事…；誕生日なのに…：明明是生日卻…
  • 句末ので可委婉留下理由；句末のに可省略相反結果並留下意外或不滿。

  1. 依筆記規則補充示範；英語語意對照

    用事があるので、今日は帰ります。 用事があるのに、帰れません。

    因為有事，所以今天要回去了。／明明有事，卻沒辦法回去。

    I have something to do, so I'm going home today. Although I have something to do, I can't leave.

    因為有事，所以今天要回去了。／明明有事，卻沒辦法回去。

  2. 依筆記規則補充示範；英語語意對照

    高いので、買いません。 高いのに、よく売れます。

    因為很貴，所以不買。／明明很貴，卻賣得很好。

    It's expensive, so I won't buy it. Although it's expensive, it sells well.

    因為很貴，所以不買。／明明很貴，卻賣得很好。

  3. 依筆記規則補充示範；英語語意對照

    休みなので、家にいます。 休みなのに、仕事があります。

    因為今天休假，所以待在家裡。／明明是休假日，卻有工作要做。

    It's my day off, so I'm staying home. Even though it's my day off, I have work to do.

    因為今天休假，所以待在家裡。／明明是休假日，卻有工作要做。

  4. 依筆記規則補充示範；英語語意對照

    静かなので、よく眠れます。 静かなのに、よく眠れません。

    因為很安靜，所以睡得很好。／明明很安靜，卻睡不好。

    It's quiet, so I can sleep well. Even though it's quiet, I can't sleep well.

    因為很安靜，所以睡得很好。／明明很安靜，卻睡不好。

  5. 原筆記例句縮寫示範；英語情境改編

    すみません、用事があるので…。

    不好意思，我有事，所以……。把婉拒留給對方理解。

    Sorry, I have something else to do.

    不好意思，我有事，所以……。把婉拒留給對方理解。

  6. 原筆記例句；英語對照補充

    昨日どうして来なかったの？約束したのに。

    昨天為什麼沒來？明明約好了。

    Why didn’t you come yesterday? You promised.

    昨天為什麼沒來？明明約好了。
